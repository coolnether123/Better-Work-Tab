# BETTER WORK TAB

Completely overhauls RimWorld's Work tab with drag-and-drop, skill overlays, automation rules, and visual customization.

## Core Features:
- Drag & Drop Reordering - Click and drag columns or pawn rows to rearrange your work tab layout. Changes persist between saves
- Skill Level Overlay - Hold SHIFT to see relevant skill levels instead of priorities. Color-coded (red→green) with "best pawn" highlighting
- Auto-Assignment Rulesets - Create smart rules to automatically assign work priorities based on passions, skills, traits, and more!
- Workloads - Save and load entire priority configurations and switch between different colony setups instantly
- Visual Dividers - Organize pawns into collapsible sections with custom labels, colors, and fonts
- Pawn Highlights - Color-code pawn rows for easy identification. Set custom background colors per pawn
- Advanced Highlighting - Highlight selected pawns, hovered rows/columns, and similar work types. Fully customizable colors and opacity
- Multiplayer Support - Sync workload presets and column reordering across players (row reordering is local-only)

## Quality of Life:
- Angled column headers save space and look great
- See colonist/bed counts
- Disable left-click closing if needed
- Right-click pawn name for quick actions (set color, rename, add divider)
- Additional float menu options for one-time work

## Compatibility:
Requires Harmony
- Compatible with every DLC
- Designed to work with most work-type mods
- May conflict with other work-tab overhaul mods (test before adding)

## Performance:
- Optimized for large colonies (50+ pawns)
- Minimal overhead when idle
- Efficient caching prevents frame drops
